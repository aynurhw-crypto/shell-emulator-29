## 1. Общее описание
Графический эмулятор командной строки UNIX-подобной операционной системы,
разработанный на языке Python с использованием библиотеки `tkinter`.
Эмулятор работает с виртуальной файловой системой (VFS) на основе
ZIP-архива полностью в оперативной памяти без распаковки на диск.

## 2. Описание функций и настроек
При запуске поддерживаются следующие параметры командной строки:
- `--vfs <путь>` — путь к ZIP-архиву виртуальной файловой системы.
- `--script <путь>` — путь к стартовому скрипту с командами.

Поддерживаемые команды эмулятора:
- `ls [путь]` — вывод списка файлов и каталогов.
- `cd [путь]` — смена текущей рабочей директории.
- `pwd` — вывод текущего рабочего пути.
- `find <шаблон>` — поиск файлов и директорий по имени.
- `rm <файл>` — удаление файла из VFS в памяти.
- `help` — вывод справки по всем доступным командам.
- `exit` — завершение работы эмулятора.

## 3. Сборка и запуск тестов
Для запуска модульных тестов и приложения выполните:
```bash
# Windows
run.bat

# Linux / macOS
chmod +x run.sh
./run.sh
```

## 4. Примеры использования
```text
default_vfs:/$ pwd
/
default_vfs:/$ ls
docs/
readme.txt
default_vfs:/$ cd docs
default_vfs:/docs$ find report
/docs/work/report.txt
default_vfs:/docs$ rm temp.txt
Removed '/docs/temp.txt'
```
